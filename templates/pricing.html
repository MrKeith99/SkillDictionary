Proposed {year} Prices

Every line re-priced by one rule, so the same skill at the same difficulty pays the same in every challenge and the same failure costs the same share everywhere. The rule lives in data/pricing.yaml; change the rule, not the numbers.

{inv_old} → {inv_new}harder line pays less than an easier one, same skill
{pen_mixed} → 0failure modes priced inconsistently (now a fixed share of the parent line)
{sum_old} → {sum_new}sum of challenge maximums ({sum_delta})
{kept}lines kept at the rulebook value (rule cannot price them yet)

The rule

Achievement = skill base × (1 + D / {d_scale}), with D the easiest instance the line covers. Harder objects are paid by bonus lines, as the rulebook already does.

Bonus or discount: parent + line together pay the rule price at the line's own D.

Penalty = a fixed share of the line it belongs to, per failure mode.

Skill base is calibrated from rulebook {base_year}: the median of price ÷ (1 + D / {d_scale}) over the skill's lines. The league's level per skill is kept; only the spread inside a skill goes. The bases are fixed in the rule, so editing lines never moves them.

Challenge totals are not rescaled: scaling a challenge would make the same skill pay differently again. Balance between challenges is set through the skill bases.
